# Zdjęcie Agnieszki Fundakowskiej

Karta zespołu i profil `#zespol/agnieszka-fundakowska` korzystają z `assets.agnieszka` (`images/agnieszka_fundowska.jpg`) zamiast placeholdera. Ten sam plik jest na stronie głównej i na stronie zespołu.

Publikacja: `npm run build` i wrzut zawartości `dist/` na FTP — bez zgody nie wysyłam.
