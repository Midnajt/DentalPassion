# Profil Stelli Stępniewskiej

Karta i artykuł `#stella-stepniewska` mają zdjęcie `images/stella-stepniewska.png` oraz bio z notatki (UMŁ, staż WIML, zachowawcza, endo pod mikroskopem, dzieci, estetyka/protetyka, medycyna estetyczna WUM, PL/EN/ES).

Tekst poprawiony składniowo (bez „Pani Doktor”, „Dr Marcina” → „dr Marcin Mazik”). Spec uzupełniony. Publikacja: `npm run build` i wrzut `dist/` na FTP — bez zgody nie wysyłam.
